🌳 AVL Tree Project

📌 Description

An AVL Tree is a self-balancing Binary Search Tree (BST) that maintains balance after insertion and deletion operations. This project demonstrates tree rotations and efficient searching techniques.

🎯 Features

- Insert nodes into the AVL Tree.
- Delete nodes from the tree.
- Search for elements.
- Maintain balance using rotations.
- Display tree elements.

🛠️ Technologies Used

- Programming Language: Python
- Data Structure: AVL Tree
- Concepts: Binary Search Tree and Tree Rotations

⚙️ Operations

- Insertion: Adds a new node.
- Deletion: Removes an existing node.
- Searching: Finds a specific element.
- Rotations: Maintains tree balance using LL, RR, LR, and RL rotations.

⏱️ Time Complexity

Operation| Time Complexity
Insertion| O(log n)
Deletion| O(log n)
Searching| O(log n)

🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Run the Python file:

python avl_tree.py

Replace "avl_tree.py" with your actual Python filename if it is different.

📚 Learning Outcomes

- Understand self-balancing binary search trees.
- Learn AVL Tree rotations.
- Improve knowledge of data structures and algorithms.
- Understand efficient searching, insertion, and deletion.

📝 Conclusion

This project demonstrates how AVL Trees maintain balance to provide efficient searching, insertion, and deletion operations. It is useful for learning advanced tree data structures and algorithms.
